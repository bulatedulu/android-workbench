## 版本 B：带工具条的输入框（融合你截图元素）

```
┌───────────────────────────────────────────────┐
│  [上下文选择区]                                 │
│  [多行输入区…]                                │
│                                               │
│  + Agent  模型  思考等级  工具图标       麦  ↑ │
└───────────────────────────────────────────────┘
```
上下文选择区：当前打开的文件，选中的文本(链接文件里的具体内容) 会自动显示在这里，文件需要点击前面的+号才被选中，选择的文本是默认选中的，可以点击前面的图标取消选中，即未选中是+号图标，选中是钉住的图标
多行输入区：用户输入的内容
+ ：图标，添加上下文，点击后可以选择文件
Agent 当前选择的agent，点击后可以选择可用的agent
模型: 当前使用的模型名称，点击可以切换模型
思考等级： 当前模型使用的思考等级，点击可以切换思考等级
工具图标：点击可以显示当前可用的工具列表
麦： 麦克风图标，点击可以语音输入
↑： 消息发送图标，点击发送消息，输入区和上下文选择区都是空的时候处于禁用状态，有内容是可点击发送消息，发送后ai处理中时是一个外圆内方的处理中状态，点击可终止AI的处理
