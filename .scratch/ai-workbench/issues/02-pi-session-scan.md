# 02 — pi 会话扫描（仅已注册项目）+ 项目树

**What to build:** 工作台自动扫描 pi 的本地会话存储，但**只保留与已注册项目目录匹配的会话**（工作目录精确匹配项目路径，或位于其子目录下），并直接挂在对应项目下展示；树视图层级为 项目 → Agent(pi) → 会话，每条会话显示标题、时间、模型。**没有「未归属会话」分组**——不属于任何已注册项目的会话不展示。若 pi 的存储目录不存在或为空，显示友好的空态提示而不是报错。

**Blocked by:** 01（扩展脚手架与项目注册）

**Status:** ready-for-agent

- [ ] 扫描 pi 的本地会话存储，解析 JSONL（含版本头、容忍版本迁移），生成会话模型（标题 / 时间 / 模型 / 存储路径 / 工作目录）
- [ ] 只保留工作目录与已注册项目匹配（精确或子目录）的会话，直接归属到对应项目
- [ ] 树视图层级为 项目 → Agent(pi) → 会话，每条会话显示标题、时间、模型
- [ ] 不属于任何已注册项目的会话不展示（无「未归属会话」分组）
- [ ] 存储目录不存在或为空时显示空态提示，不崩溃
- [ ] PiProvider 有基于临时目录 + 真实 pi 格式 fixture 的测试（扫描、读取、版本容忍、路径匹配边界）
