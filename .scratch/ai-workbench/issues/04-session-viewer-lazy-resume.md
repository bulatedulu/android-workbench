# 04 — 会话视图：懒加载恢复

**What to build:** 用户单击树里的任意会话，Webview 快速只读加载并展示完整对话内容（每条消息的角色、时间、文本），可滚动浏览，**不启动任何进程**。视图底部有一个输入框（占位提示「点击此处继续对话」）；当用户**聚焦输入框**时，视为明确的交互意图，触发「恢复会话」——在集成终端运行 pi 并加载该会话，提示用户到终端继续。只读阅读零开销，交互时才启动 pi。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 单击会话打开 Webview，快速只读展示完整消息序列（角色、时间、内容），不启动任何进程
- [ ] 严格只读：无编辑、删除、改写会话的任何入口
- [ ] 视图底部有输入框，占位提示「点击此处继续对话」
- [ ] 聚焦输入框触发恢复：在集成终端运行 pi 的继续命令加载该会话（命令执行器可注入以便测试）
- [ ] 内容读取走 PiProvider 原地读取（不复制、不落库）
- [ ] 消息渲染与聚焦触发逻辑有可验证的验收手段（组件测试或手工核对清单）
